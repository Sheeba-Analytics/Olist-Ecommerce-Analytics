Olist E-commerce Analytics

An end-to-end Brazilian e-commerce analysis developed using Power BI, Power Query and DAX. The project transforms the Olist public dataset into interactive dashboards covering revenue, products, sellers, delivery performance, payments, customer behaviour, reviews, RFM segmentation and cohort analysis.



Project Objectives

Analyse overall revenue and order performance.

Identify leading product categories and sellers.

Evaluate delivery time and late-delivery performance.

Understand payment behaviour and instalment usage.

Examine customer activity and repeat purchases.

Segment customers using RFM analysis.

Track customer retention through cohort analysis.

Present key business findings in an executive insights page.
